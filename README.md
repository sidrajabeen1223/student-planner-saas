# Student Planner SaaS

A beginner-friendly student planner web app built with Python Flask, SQLite, HTML, and CSS.

## Features
- Add homework, assignments, and study tasks
- Set a subject and due date
- Mark tasks complete or pending
- Delete tasks
- Dashboard showing total, completed, and pending tasks
- Tasks are stored in a local SQLite database

## Requirements
- Python 3.10 or newer
- pip

## Run locally
1. Extract this ZIP file.
2. Open a terminal in the `student-planner-saas` folder.
3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the app:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.
